## Features at a Glance

✨ **Dynamic Theming** - Uses colors from pywal with Gruvbox dark fallback  
🖼️ **Custom Background** - Displays your wallpaper  
🔄 **Real-time Updates** - WebSocket support with automatic fallback  
📱 **Responsive** - Works on desktop and mobile  
⏰ **Digital Clock** - 24-hour or 12-hour format  
🔍 **Web Search** - Integrated search with multiple providers  
📊 **System Stats** - Real-time CPU, memory, disk, network monitoring  
🌤️ **Weather** - Hourly and daily forecasts  
📰 **RSS Feeds** - Auto-rotating news carousel  
🔗 **Hierarchical Links** - Organize links in categories  
✏️ **In-Browser Editing** - Add, edit, delete links directly  
⚡ **Lightweight** - Inline CSS and JavaScript for simplicity  

## System Requirements

- **Python:** 3.10 or higher
- **OS:** Linux (systemd or XDG autostart) or BSD (FreeBSD, OpenBSD, NetBSD)
- **Browsers:** Modern browsers with JavaScript support
